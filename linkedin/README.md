# LinkedIn launch kit — Lead CRM

| File | Use |
|---|---|
| [POST.md](POST.md) | Main post (~1,300 characters) + a short and a technical version |
| [KEY_HIGHLIGHTS.md](KEY_HIGHLIGHTS.md) | 10 plain-language highlights and the project numbers |
| [PROJECT_ENTRY.md](PROJECT_ENTRY.md) | Profile "Projects" entry, skills, Featured line, headline idea |
| `images/01-cover-1200x1200.png` | Main post image (square) |
| `images/02-highlights-1080x1350.png` | Portrait image for a second post or the first comment |
| `images/03-how-it-works-1200x627.png` | Landscape image for a follow-up / technical post |
| `images/04-featured-1200x627.png` | Profile "Featured" / "Projects" thumbnail |

Images are drawn by `images/make_images.py` (`python3 make_images.py`); edit the text there and re-run to change them.

**Posting tips:** post Tuesday–Thursday, 8–10 am your time; reply to every comment in the first hour; put any link (GitHub / demo video) in the first comment, not in the post; follow up a week later with the technical version and the how-it-works image.
